# Иллюстрации устройств

Изображения `concept-states.png` созданы встроенным генератором изображений на основе `assets/workshop-pixel.png` и предназначены для художественной проработки игровых предметов. Это единые листы концептов, а не готовые послойные спрайты или анимации. Изображённые устройства и технические детали могут быть условными.

Шаблон запроса (название устройства подставляется отдельно):

> Create one isolated transparent-background pixel art asset sheet for a cozy 1990s repair game, matching the pixel density, warm amber lighting and detailed hand-crafted pixel style of the provided workshop reference. Subject: [device]. Draw FOUR distinct views of exactly the same single object, arranged in a single row with generous transparent margins, equal size: (1) complete exterior, (2) cover removed revealing components, (3) exploded view with clearly separated internal components, (4) repaired and completely reassembled exterior matching view 1. Each view is standalone and unobstructed, consistent near-top-down perspective; no hands, no people, no furniture, no background, no text, no labels, no UI, no unrelated devices. The four views represent stages of one [device].

Перед добавлением заказа проверить конструкцию, сопоставимость видов, прозрачность, масштаб и места взаимодействия. Для игры нужны отдельные слои и реальные игровые состояния, включая винты, установленные детали и понятную обратную связь. В данный момент фрагменты листа кассетного плеера используются для его собранного и открытого состояния; остальные концепты ещё не подключены к заказам.
