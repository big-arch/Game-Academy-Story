# Серии предметов для мастерской

Каждый заказ получает собственный предмет, подходящий по масштабу и перспективе к столу. В серии нужны собранный предмет, открытый корпус, разложенные внутренние детали и собранный после ремонта предмет. Состояния должны описывать одну и ту же модель: расположение деталей и цвет корпуса не должны прыгать между кадрами. Иллюстрации — исходные концепты; перед применением их надо проверить, разделить на слои и связать с интерактивными точками, чтобы ремонт не был просто сменой картинок.

| Предмет | Идея неисправности | Детали для ремонта |
|---|---|---|
| Кассетный плеер | Лента не движется, звук глухой | Крышка, винты, пассик, головка, прижимной ролик |
| Видеокамера | Не читает кассету, теряет питание | Аккумулятор, отсек, ремень, шлейф, плата |
| Видеоплеер VHS | Не принимает кассету | Лоток, ремни, ролики, механизм загрузки |
| Пейджер | Не включается | Батарея, контакты, корпус, плата, дисплей |
| Телефон | Плохо заряжается, западают клавиши | Аккумулятор, разъём, клавиатура, контакты, плата |
| КПК | Не реагирует на касание | Стилиc, экран, шлейф, плата, батарея |
| Игровая приставка | Не видит картридж | Крышка, разъём картриджа, контакты, плата |
| Телевизор | Нет звука | Корпус, динамик, соединения, плата |
| Пульт | Часть кнопок не работает | Батарейки, крышка, контакты, плата, резиновые кнопки |
| Магнитофон | Портит плёнку | Пассики, ролики, головка, механизм кассеты |
| Пылесос | Плохо тянет и перегревается | Фильтр, пылесборник, шланг, вентилятор |

Это художественные игровые сценарии. Для телевизора и сетевых приборов необходимо отдельно спроектировать правдоподобную безопасную игровую последовательность, а не давать игроку инструкции по работе с опасными частями.

Материалы каждого устройства хранить в отдельной подпапке `assets/devices/`. Награда и баланс уже находятся в локальном сохранении; дополнительные заказы подключаются постепенно после готовности иллюстраций и механики.
