## Изменения

- Камера «Мастерская, 1996» доступна после восьми работ и двух предыдущих возвратов с полки. Новый Михалыч, два вопроса, билет внутри, запись Н. и переход к бирке телефона.
- Мультиметр только находит обрыв. Для камеры и КПК теперь нужна отдельная пайка; зависимости не позволяют паять наугад или завершить ремонт после одного измерения.
- Полка не позволяет подменить текущий ремонт. Причины блокировки учитывают предыдущие главы; будущие неготовые заказы не обещают открытие только по счётчику работ.
- Исправлен `audit:art`: новые винты `[x,y,size]` больше не ломают проверку; учитываются скрытые точки ремонта.
- Устранена ошибка при неудачном сбросе винта: расстояние считалось уже после обнуления начала перетаскивания. Винты на столе доступны с клавиатуры; возвращающиеся винты исключаются из взаимодействий.
- Приборы закрываются с очисткой обработчиков и анимации по Escape, смене инструмента, выходу в меню и изменению размера окна.
- Исправлены подписи новых инструментов `undefined`, убраны нерелевантные приборы из выбора для очистки/ручной установки. Находки камеры перенесены, чтобы не перекрывать центр точки очистки.
- Прощание после просмотра записи на уже завершённом заказе сохраняет переход к сюжетной бирке.
