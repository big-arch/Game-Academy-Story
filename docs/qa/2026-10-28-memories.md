# Экраны и личные истории после ремонта

## Реализовано

- Шесть типов устройств, 13 сцен под конкретного клиента: пейджер, телефон, КПК, камера, телевизор, ноутбук. Положение стекла сверено с PNG; ноутбук использует экран в рисунке комнаты.
- Запуск с короткой загрузкой, мягкая подсветка и тихий двухтональный сигнал. Reduced motion убирает анимации. Настройка эффектов распространяется на сигнал.
- Полный текст открывается касанием экрана. Есть необязательное продолжение: расшифровка, звонок, копия архива, рендер, просмотр записи. Реплика владельца соответствует выполненному продолжению.
- Альбом сохраняется между заказами и перезапусками. За повторное чтение не начисляются монеты; текущие награды не менялись.
- До успешной проверки, с открытой крышкой или незакреплённым винтом история недоступна. После завершения заказа экран остаётся доступным, остальные органы ремонта блокируются.

## Проверка

- `npm test`: 30/30, в том числе наличие контента для каждого клиента с экраном, координаты стекла, переход успешной проверки к включённому экрану, повторная разборка, сохранение и отсутствие дублирования/дополнительных монет.
- `npm run audit:art`: девять устройств, успешно. `node --check` и `git diff --check`: успешно.
- Браузерная проверка на отдельном origin `127.0.0.1:4177` через явно названные тестовые сохранения в `temp/qa-memories.html`. Проверены финальные состояния всех шести экранов. Это проверка сцены после ремонта; весь ремонт каждого устройства в браузере заново не проходился.
- Пейджер Светланы: на стекле «143», чтение и расшифровка, затем альбом 1/13. Телефон Димы: СМС → соединение → разговор, на стекле «МАМА», обычная награда 100 монет при возврате. Ноутбук Веры: архив на экране → процесс копирования → подтверждение копии. Просмотрены стекло КПК, окно камеры и футбольный эфир телевизора.
- Меню с альбомом и история телефона проверены на 320×568; документ ровно 320×568, нижняя граница меню 556. Все шесть экранов проверены на 390×844 без прокрутки документа. Окно чтения использует нативный dialog с клавиатурным фокусом и Escape.
- Снимки: `pager-memory-screen.png`, `phone-memory-call.png`, `laptop-memory-screen.png`, `laptop-memory-backup.png`, `television-memory-screen.png`.

Сцены звонка/записей текстовые: голосовые реплики и видеоролики не добавлены. Изменения Supabase в эту работу не входили; пользовательское сохранение не использовалось для тестовых ремонтов. Установка APK на физический телефон не проверялась.
