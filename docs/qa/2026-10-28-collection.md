# Стеллаж коллекции под окном

Основа: `1f45008`, включая новые нарисованные этапы комнаты и ранее добавленный выбор одного узла ремонта.

## Изменения

- Панель значков справа заменена деревянным стеллажом под окном, в области, отмеченной пользователем.
- Два ряда, 14 мест. Показываются только уже починенные/возвращённые типы, без повторов. Учтена сюжетная шкатулка, всего сейчас 13 типов.
- Используются существующие изображения отремонтированных устройств. Ноутбук показан из прозрачного изображения комнаты через SVG-область просмотра; исходные PNG не менялись.
- Первое нажатие увеличивает стеллаж: маленькие изображения в комнате не требуют точного попадания пальцем. В крупном виде можно выбрать предмет и прочитать сохранённые воспоминания, включая продолжение, если игрок его уже открыл.
- В фоне главного меню стеллаж декоративный, в комнате и предпросмотре доступен. При открытии закрываются инструменты активного ремонта. Заказ, деньги и сохранение не меняются.
- В мобильную сборку добавлен вид отремонтированного кассетного плеера.

## Проверено

- `npm test`: 43/43, включая отсутствие дублей, исключение незавершённых заказов, сюжетные предметы, существование изображений и вместимость стеллажа.
- В браузере использован отдельный origin `127.0.0.1:4180` и тестовое сохранение из `temp/qa-collection.html`, с полной коллекцией и открытым обычным заказом.
- На 390×844 просмотрены стеллаж, крупные полки и ноутбук с историей Веры. На 320×568 просмотрены телефон с СМС/разговором, возврат к полкам и вся коллекция.
- На 320×568 стеллаж содержит 13 изображений; пересечение его прямоугольника с котом и ремонтируемой приставкой — 0 пикселей. Окно истории телефона: x15, y45.7, 290×476.7; документ ровно 320×568.
- Ошибок в консоли тестовой вкладки не обнаружено.
- `npm run apk`: BUILD SUCCESSFUL, отладочный APK 80.7 МБ. Сверены JS/CSS коллекции, HTML, кассетный плеер и прозрачный ноутбук внутри APK с исходниками.
