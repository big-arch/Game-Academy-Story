# Похожие игры: что берём в «Мастерскую историй»

Цель — удержание внимания: каждый заказ должен быть чуть сложнее и чуть личнее предыдущего, а между заказами должно быть «зачем вернуться завтра».

| Игра | Что в ней держит | Что берём к нам |
|---|---|---|
| **Assemble with Care** | Каждый ремонт — глава истории; вещь раскрывает отношения людей | Уже есть: клиент + вещь + финал. Добавить «главы» — недели с общей темой |
| **Unpacking** | История без слов, через предметы и их место | Находки внутри корпуса (сделано), следы на корпусе (сделано) |
| **A Little to the Left** | Удовольствие от мелкой точной сортировки | Сортировка винтов по размеру: у каждого отверстия свой винт |
| **Strange Horticulture** | Дедукция по справочнику: описание → улики → вывод | «Справочник мастера»: симптомы → таблица причин, записи открываются с опытом |
| **Papers, Please** | Правила меняются, растёт сложность, моральные выборы | Правила недели («сегодня нет запчастей — только чистка»), выбор: чинить быстро или бережно |
| **Coffee Talk** | Постоянные клиенты, их истории тянутся через дни | Возвращающиеся клиенты (Зоя Михайловна, Миша, Михалыч) с продолжением |
| **Spiritfarer** | Отношения с персонажами и прощание | Финальные главы клиентов, письма-благодарности на стене мастерской |
| **Car Mechanic Simulator** | Износ деталей, покупка запчастей, бюджет | Склад запчастей: новую батарейку/ремень надо купить; дорогие и дешёвые варианты |
| **PC Building Simulator** | Диагностика по шагам, тестовые приборы | Мультиметр: проверка цепи по точкам, поиск обрыва |
| **Tiny Bookshop / Cozy Grove** | Ежедневный ритм, маленькие улучшения пространства | День/вечер, очередь из 2–3 заказов, улучшения мастерской меняют комнату |
| **Behind the Frame / Lost in Play** | Мини-головоломки внутри предметов | Защёлки корпуса в правильном порядке, шифр на кассете, кодовый замок шкатулки |

## Новые механики ремонта (по приоритету)

1. **Находки внутри** — записка, фото, билет в открытом корпусе. *Сделано для 9 клиентов.*
2. **Винты разного размера** — длинный, короткий, с шайбой. Открученные лежат у своих отверстий; перепутал — винт не закручивается и клиент получит царапину.
3. **Скрытая вторая поломка** — после первого ремонта проверка не проходит, внутри находится новая причина (пример: телефон зарядился, но не ловит сеть — окислена антенна).
4. **Мультиметр** — инструмент: коснуться двух точек на плате, стрелка показывает, есть ли цепь. Найти обрыв среди 3–4 дорожек.
5. **Пайка** — удерживать паяльник, пока шкала в зелёной зоне; перегрел — потемнела плата, минус чаевые.
6. **Защёлки корпуса** — пластиковой лопаткой по кругу в правильном порядке; торопишься — защёлка ломается (нужна изолента, клиент заметит).
7. **Склад запчастей** — батарейки, ремни, фильтры покупаются за монеты; оригинал дороже, но клиент рад больше.
8. **Бережность** — счётчик «аккуратности» заказа: лишние действия, сорванные защёлки, перепутанные винты снижают чаевые.
9. **Справочник мастера** — записи о поломках открываются после первого ремонта; на сложных заказах симптомы надо сверить со справочником.
10. **Неделя-глава** — 5 заказов, общая тема и правило недели, в конце письмо и улучшение мастерской.

## Удержание между сессиями

- Очередь заказов на завтра видна заранее (2–3 карточки с крючком в первой строке).
- Возвращающиеся клиенты: продолжение истории через 1–2 недели.
- Стена благодарностей: фото и письма клиентов в мастерской.
- Главный сюжет мастерской (см. `docs/SCENARIO.md`) раскрывается понемногу в каждой главе.
