# Мастерская историй — прототип

Браузерный прототип мобильной игры: 12 типов заказов, клиенты с историями, диагностика, разборка и сборка техники, следы на корпусах, чаевые и обустройство комнаты. Музыка и эффекты включаются раздельно; плейлист мастерской перемешивается. Это ещё не релиз для магазина.

## Запуск

Заказы теперь выдаются последовательно кнопкой «Принять заказ»: пейджер → пульт → телефон → приставка → КПК → кассетник → магнитофон → видеоплеер → камера → пылесос → ноутбук → телевизор. Завершённые истории сохраняются в коллекции; текущий ремонт после обновления продолжается с прежнего места.

Коснитесь детали, чтобы выбрать инструмент рядом с ней. Винт требует удержания отвёртки, очистка выполняется движением по зоне, деталь нужно перетащить в гнездо. На сложности от 3 для установки руками нужно совместить треугольные метки поворотом. Для клавиатуры доступны Enter и Tab, включая отдельное выполнение очистки. Нижняя панель содержит общие действия, а не поиск инструментов.

Лежанка отводит коту отдельное место отдыха, лампа за 120 монет открывает лупу ×1.4 в инструментах детали; повторное нажатие убирает увеличение. Гирлянда остаётся визуальным украшением. На стене появляются значки завершённых историй.

После успешной проверки у пейджера, телефона, КПК, камеры, телевизора и ноутбука оживает экран. Коснитесь его, чтобы открыть личную историю владельца. Для обычных и сюжетных клиентов написаны отдельные сообщения, заметки и записи. Необязательное действие (звонок, копия архива, просмотр фрагмента) меняет прощальную реплику. Это постановочные игровые сцены с текстом, не реальные звонки, видео или операции с пользовательскими файлами. Найденное сохраняется в «Альбоме историй» в главном меню, также между заказами. При повторной разборке экран гаснет до новой успешной проверки.

Требуется Node.js 20.11 или новее. В папке проекта выполните `npm start`, затем откройте http://127.0.0.1:4173. Управление мышью или касанием. Прогресс хранится в браузере. При переходе в главное меню состояние заказа сохраняется.

Перед первым запуском выполните `npm install`: `npm start` упаковывает `supabase-js` в `vendor/supabase.js`, и игра загружает его локально, без CDN.

В меню и после завершения заказа доступно «Обустройство»: лежанка (80 монет), гирлянда (100), тёплый свет (120). Сначала показывается предпросмотр, монеты списываются только кнопкой покупки. Купленные предметы сохраняются в локальном прогрессе и остаются при смене или повторе заказа. Старое улучшение лампы учитывается как уже приобретённое.

## Мобильная сборка (Capacitor)

- `npm run build` — собрать `www/`: только файлы, нужные игре; `models/`, `temp/` и исходники музыки туда не попадают.
- `npm run cap:sync` — собрать и скопировать в `android/` и `ios/`.
- `npm run android` / `npm run ios` — открыть проект в Android Studio / Xcode. Для iOS нужен Mac.
- `npm run apk` — собрать отладочный APK в `dist/workshop-stories-debug.apk`, его можно поставить на телефон. Нужен JDK 21 в `~/.jdks` (Java 25 из Android Studio для Gradle 8.14 слишком новая), а из-за кириллицы в пути проект на время сборки подключается буквой диска через `subst`.
- `npm run assets` — пересоздать иконки и сплэш из `resources/` (`icon-only.png`, `icon-foreground.png`, `icon-background.png` — 1024×1024, `splash.png` и `splash-dark.png` — 2732×2732).

Идентификатор приложения — `com.bigarch.workshopstories` (`capacitor.config.json`). Ориентация закреплена портретная.

Проверка: `npm test`. Лицензии музыки, плейлист и звуки описаны в `music/README.md`.

`npm run audit:art` проверяет координаты винтов девяти устройств по прозрачности реальных PNG и контур приставки. Нужны Python и Pillow (они также используются для нарезки графики). Обзор похожих игр, использованного открытого кода и дальнейших механик — в [research/repair-gameplay.md](research/repair-gameplay.md).

Вдохновение: [Assemble with Care — заметки разработчиков](https://ustwogames.co.uk/news/building-assemble-with-care/), [рекомендации по размерам элементов управления](https://gameaccessibilityguidelines.com/ensure-interactive-elements-virtual-controls-are-large-and-well-spaced-particularly-on-small-or-touch-screens/). Источники использованных материалов перечислены в библиотеке и документации проекта.

Для прототипа отдельные изображения покадрового кота в `assets/sprites/` вырезаны из находящегося в проекте `models/PACK/cat 2` без изменения рисунка. По составу набор похож на Last tick, однако происхождение файла и условия для финального релиза ещё нужно подтвердить. Сведения о материалах и лицензиях — в `models/README.md`, `material-library/README.md` и `music/README.md`.

## Инструменты для графики

- `pwsh scripts/adobe/run-photoshop.ps1 <устройство>` — режет `assets/devices/<устройство>/concept-states.png` на детали по контуру (`scripts/split-parts.py`, рамки деталей в `parts.json`) и собирает в Photoshop `source/<устройство>-parts.psd`, где каждая деталь — свой слой.
- `pwsh scripts/adobe/run-illustrator.ps1` — рисует в Illustrator векторную монету `assets/ui/coin.svg` (исходник `assets/ui/source/coin.ai`).

COM-регистрация Photoshop и Illustrator на этой машине пустая, поэтому скрипты `.jsx` передаются программам как файлы. Photoshop и Illustrator при этом открываются на экране.
- Кот в Aseprite: `assets/sprites/cat/source/cat.aseprite` — анимация на таймлайне, теги `idle`, `walk`, `wash`, `sleep`, `stretch` (скорость как в `cat.js`). После правок в Aseprite выполните `pwsh scripts/aseprite/export-cat.ps1` — теги выгрузятся в `assets/sprites/cat/<тег>.png`, которые читает игра. Если меняете число кадров в теге, поправьте `ANIMS` в `cat.js`. `-Build` заново собирает `.aseprite` из текущих PNG.

## Сюжетная полка

После письма Лёвы появляются вещи «НЕ ГОТОВО». Пульт доступен после двух работ, пейджер «143» после пяти и возврата пульта, камера «Мастерская, 1996» после восьми и возврата пейджера. У камеры отдельные диалог, находка и запись, продолжающие сюжет. Телефон и шкатулка пока запланированы.

Мультиметр определяет обрыв по `OL`, а пайка восстанавливает контакт отдельным действием. Установить винт со стола можно перетаскиванием или с клавиатуры (Tab, Enter). Проверка последней итерации: `docs/qa/2026-10-28-chapter3.md`.
