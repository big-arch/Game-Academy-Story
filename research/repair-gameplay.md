## Что уже взяли из открытого кода

Из Phaser взята функция проверки точки внутри многоугольника: `open-source/phaser/Contains.cjs`. Источник, SHA и полная MIT-лицензия сохранены рядом. Она используется в проверке контура приставки перед сборкой. Весь движок Phaser в игру не добавляли.

- Исходник: https://github.com/phaserjs/phaser/blob/master/src/geom/polygon/Contains.js
- Документация локальных областей ввода: https://docs.phaser.io/phaser/concepts/input
- Escoria — открытый MIT-фреймворк приключенческих игр для Godot: https://escoria-framework.org/ . Полезны подходы к диалогам, инвентарю и состоянию взаимодействий. Его код в текущую браузерную игру не переносили.

Лицензия движка не даёт права брать чужую музыку или изображения из примеров. Любой следующий импорт должен иметь источник и подходящую лицензию.

## Три следующие механики — пока план

1. **Очистка движением.** Игрок проводит кистью по пыли: она уходит под инструментом, а не исчезает целиком после клика. Площадь очищенного участка определяет завершение. Для спирта — отдельные короткие движения по контактам. Начать с приставки, затем переиспользовать для других устройств.
2. **Диагностика по наблюдениям.** До выбора причины доступны пробный запуск, звук и измерение. Например, питание в норме, картинка мелькает при движении картриджа: игрок сам связывает признаки с контактами. Не выдавать диагноз сразу в описании заказа.
3. **Подбор и установка детали.** У кассетника несколько ремней; нужно сопоставить размер и посадку, затем натянуть выбранный на шкивы. У пейджера — полярность батареи, у камеры — ориентация шлейфа. Сложность появляется из устройства предмета.

После этого — варианты неисправностей одного предмета и бонус за аккуратную работу. Спокойный темп сохраняем: сложность через наблюдение и действие, без обязательной гонки по таймеру.

## Пайплайн

Сейчас: исходники и слои → PNG видов устройства → координаты крепежа/рабочих зон в `devices.js` → `npm run audit:art` → `npm test` (полные циклы всех девяти устройств) → браузерная проверка 320×568 и 390×844 → APK.

Проверка графики контролирует непрозрачность под центром каждого винта, диапазон координат зон ремонта и заданный контур приставки. Она не оценивает художественное качество и не заменяет просмотр открытого/закрытого состояния вручную.

Следующее улучшение пайплайна: хранить крепёж и зоны ремонта в именованных slices Aseprite, экспортировать PNG + JSON и получать координаты автоматически. В текущую сборку этот экспорт для устройств ещё не встроен. Официальный CLI: https://www.aseprite.org/docs/cli/ . Экспорт анимационных тегов кота уже существует в `scripts/aseprite/export-cat.ps1`.
