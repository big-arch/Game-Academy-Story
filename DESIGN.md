# Визуальный язык мастерской

## Scene
Игрок вечером ремонтирует памятные вещи за деревянным столом, при тёплом свете лампы, на фоне дождливого синего города. Тёмные поверхности и янтарный акцент повторяют существующий рисунок комнаты.

## Palette
Основной тёмный коричневый oklch(0.23 0.025 48), поверхность oklch(0.30 0.035 52), тёплый текст oklch(0.90 0.065 82), вторичный текст oklch(0.74 0.055 75), акцент oklch(0.72 0.105 68). Сохранять исходную палитру существующих пиксельных изображений.

## Typography
Consolas, Courier New, monospace для кратких надписей и чисел; Georgia для историй клиентов. Читаемые подписи без излишнего декоративного текста. Основные кнопки не ниже 44px.

## Layout
Портретная игровая поверхность 936:1681, по высоте окна. Комната и устройство остаются на одном экране. Инструменты открываются у выбранной детали; общие действия и сообщения остаются в нижнем доке. Следующий заказ выдаётся автоматически по сложности кнопкой «Принять заказ». Дополнительные самостоятельные экраны имеют понятный возврат к ремонту.

## Components and Motion

Коллекция встроена в комнату: деревянный стеллаж под окном, два ряда ячеек с игровыми изображениями устройств. Сам стеллаж имеет общую удобную область нажатия; отдельные предметы выбираются в увеличенном представлении с крупными кнопками. Эмодзи не заменяют изображения техники. Стеллаж не пересекается с котом и рабочей областью.
Тонкая тёплая рамка, простой контрастный фокус, подчёркнутое выбранное состояние. pixelated для спрайтов. Плавные короткие переходы интерфейса; фоновое движение и покадровые анимации отключаются при reduced motion. Состояния покупки: предпросмотр, доступна, не хватает монет, установлено.
